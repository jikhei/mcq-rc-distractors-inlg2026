# MCQ Reading Comprehension Distractors (INLG 2026)

This repository contains code and data associated with the paper **"Distractors for Multiple-choice Questions for Reading Comprehension"**.

OpenReview: <https://openreview.net/forum?id=jd2rOhC2A0>

## Repository Contents

- `code/`: notebooks and scripts for SFT training, inference, and output compilation.
- `data/`: distractor datasets, ranking results, metric outputs, human evaluation files, and analysis notebooks.

The repository is organized for research release alongside the paper. See the README files in individual subdirectories for more specific notes about each component.
