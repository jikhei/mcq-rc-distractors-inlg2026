# K-Fold Data

This directory stores the k-fold data for B distractors. The corresponding k-fold data for C distractors are stored outside this directory.

`inference.ipynb` can be used to:

- generate distractors in batch or one by one;
- detect invalid distractors, with a maximum of 10 attempts;
- extract distractors from model outputs using regular expressions.

Please review the notebook before running it and adjust the local paths for your environment.
