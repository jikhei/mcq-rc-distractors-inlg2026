# B and C Distractors

## `ord_distractors_full`

- `*_span_full`: span expanded to a complete sentence
- `*_distractor_com`: distractor completed with the question context, for example: "Who is Edward? A prince." -> "Edward is a prince."

## `_gpt4o`

A zero-shot version of B distractors generated by GPT-4o with IDD by mistake.
